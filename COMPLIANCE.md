## Original name

## Original code and copy

- All code in this repository was written from scratch for this
  project. All documentation is original prose.
- The only external material studied was the **file format** of the
  Arena skill (github.com/Jakeschincariol/arena-skill, MIT-licensed):
  its `arena.json` state schema, its per-round verdict-file layout,
  its rubric weights (30/25/15/20/10) and its 5-calls-per-match
  accounting. These are functional facts required for interoperability
  with a format other software writes — podiumproof *reads* that
  format the way a log parser reads a log format. No code, text,
  strategy content, or structure was copied from that project; the
  audit's checks, judge model, replay method, claims, and stamps are
  original to podiumproof. (The format's own licence is MIT in any
  case, and this paragraph is the attribution of the idea.)
- The landscape analysis that motivated this tool surveyed published
  research (self-consistency, best-of-N verifiers, judge-bias studies,
  tournament theory). podiumproof implements none of those systems; it
  measures runs of them. Citations in the README are to ideas, in the
  ordinary scholarly way.
